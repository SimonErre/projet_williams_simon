# TP 01 — Formulaire d’inscription (Sign Up) avec page récapitulative

## Objectif pédagogique

Ce TP 01 a pour but de vérifier vos compétences de base en technologies web standard (HTML5, CSS3, JavaScript Vanilla).
Vous allez réaliser une page web statique permettant à un nouvel utilisateur de créer un compte (Sign Up) en saisissant ses informations personnelles, puis d’afficher une page récapitulative après validation.

## Consignes

### 1️⃣ Structure du formulaire

Créez une page `index.html` contenant un formulaire d’inscription avec les champs suivants :

- Login (champ texte, requis)
- Mot de passe (champ password, requis)
- Confirmation du mot de passe (champ password, requis)
- Nom (champ texte, requis)
- Prénom (champ texte, requis)
- Adresse (champ texte, requis)
- Email (champ email, requis)
- Téléphone (champ texte, requis)
- Date de naissance (champ date, requis)
- Ajoutez un bouton S’inscrire.

### 2️⃣ Mise en forme (CSS)

- Créez une feuille de style `style.css` pour rendre le formulaire lisible et attractif.
- Centrez le formulaire sur la page.
- Rendez la mise en page responsive.
- Stylisez les champs, le bouton, les messages et la page récapitulative.

### 3️⃣ Comportement JavaScript

- Créez un fichier `script.js` qui gère la logique suivante :
  - Vérifier que tous les champs sont remplis.
  - Vérifier que l’email est valide.
  - Vérifier que le mot de passe et la confirmation correspondent.
  - Si une erreur est détectée, afficher un message d’erreur clair sans recharger la page.
  - Si tout est correct, masquer le formulaire et afficher une page récapitulative (dans la même page, pas de redirection externe) contenant toutes les informations saisies sauf le mot de passe.

### 4️⃣ Contraintes

- N’utilisez aucune bibliothèque externe ni framework.
- Les fichiers doivent être séparés : `index.html` / `style.css` / `script.js`.
